# Fresco

The official Cleitext page builder: drag containers and elements onto the page, style each element for desktop, tablet and mobile, and use global colors and fonts. Fresco Pro adds more elements and the theme builder.

## What is new in 2.12

- **Flip box** (new free element): a front side (image or color background, icon, title, text) and a back side (title, text, a button with its link). It turns on hover, and on keyboard focus or a tap, so it works with a keyboard and on touch screens. Effects: flip (left, right, up, down) or fade.
- **Image carousel**: each image can have its own link (under **Images**); it wins over the carousel's link. WPBakery carousels with custom links are imported with each image's link.
- **Containers**: the width and boxed width also take a size written as CSS (the **Custom** button next to the slider), such as `calc(100% - 40px)`, `min()`, `max()` or `clamp()`. Margins can be negative.
- **Background videos** (YouTube, Vimeo): the video is held until the visitor accepts it when the Privacy plugin is active; the background image shows until then. MP4 and WebM files play at once.
- **Text**: list markers (`list-style-type`, `<ol type>`, `<ul type>`) are kept.
- **Image**: with only a maximum width set, the image still never gets wider than its box and keeps its proportions.
