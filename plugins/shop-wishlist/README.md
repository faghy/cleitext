# Wishlist

A Cleishop add-on (official plugin, free): customers save products for later.

- **A heart** on every product card (catalog, categories, product blocks) and below «Add to cart» on a product's page. It is added in the browser, so the pages stay cached for everyone.
- **Without an account too**: a guest's list lives in a cookie (needed for the service, like the cart's) and joins the account's list when they sign in.
- **The list** at `/wishlist` (and `/it/wishlist`…) shows Cleishop's own product cards, with prices, stock and «Add to cart»; the heart takes a product off the list.
- **Share**: a read-only link to the list, by email, Facebook, Pinterest, WhatsApp, or copied.
- **Header count**: the «Wishlist link» block shows the number of products saved.
- **Import from YITH WooCommerce Wishlist**: the export of WooCommerce Import holds the lists; customers are found among those it imported, products by SKU.
- **Admin**: Plugins → Wishlist, with the number of lists and the most wished products.

Needs Cleitext 0.100 or later and Cleishop 1.13.1 or later (its `shop` service, plugin API 1.73).
