# Lista desideri

Un componente aggiuntivo di Cleishop (plugin ufficiale, gratuito): i clienti salvano i prodotti per dopo.

- **Un cuore** su ogni scheda prodotto (catalogo, categorie, blocchi di prodotti) e sotto «Aggiungi al carrello» nella pagina del prodotto. Viene aggiunto nel browser, così le pagine restano in cache per tutti.
- **Anche senza account**: la lista di un ospite sta in un cookie (necessario al servizio, come quello del carrello) e si unisce a quella dell'account quando accede.
- **La lista** su `/wishlist` (e `/it/wishlist`…) mostra le schede prodotto di Cleishop, con prezzi, disponibilità e «Aggiungi al carrello»; il cuore toglie un prodotto dalla lista.
- **Condivisione**: un link in sola lettura alla lista, via email, Facebook, Pinterest, WhatsApp, o copiato.
- **Conteggio nell'header**: il blocco «Link alla lista desideri» mostra quanti prodotti sono salvati.
- **Import da YITH WooCommerce Wishlist**: l'export di WooCommerce Import contiene le liste; i clienti vengono cercati tra quelli che ha importato, i prodotti per SKU.
- **Pannello**: Plugin → Lista desideri, con il numero di liste e i prodotti più desiderati.

Richiede Cleitext 0.100 o successivo e Cleishop 1.13.1 o successivo (il suo servizio `shop`, API dei plugin 1.73).
