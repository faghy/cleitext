# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately, through GitHub's **Report a vulnerability** button in the [Security tab](https://github.com/faghy/cleitext/security) of this repository. Do not open a public issue.

Include the affected version, the steps to reproduce and the impact you expect. You will get an answer within a week; fixes for confirmed issues are released as soon as possible and credited in the release notes, unless you prefer otherwise.

## Supported versions

Only the latest release receives security fixes while Cleitext is before 1.0.

## How Cleitext is secured

The [OWASP ASVS checklist](docs/ASVS.md) describes the measures in place and the open items.
